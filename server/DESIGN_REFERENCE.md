# Hellfest Ticketing Clone - Design Reference

## Visual Analysis

### Color Palette
- **Primary Background**: Very dark (almost black) - `#0a0a0a` or similar
- **Accent Color**: Red/Crimson - used for highlights and text emphasis
- **Text**: Light gray/white for contrast
- **Secondary**: Lime/neon green - used for interactive elements and highlights

### Typography
- **Display Font**: Bold, metallic-style serif (Hellfest branding)
- **Body Font**: Clean sans-serif for readability
- **Hierarchy**: Large bold headings with red accents

### Layout Structure
- **Header**: Logo (H symbol) + Language selector (FR/EN) + Navigation links
- **Hero Section**: Large banner image with Hellfest logo overlay
- **Main Content**: Centered text area with status information
- **Call-to-Action**: Links to "Espace Client" and "Revente de billets"
- **Footer**: Social media icons (Forum, Facebook, Instagram, YouTube, Discord, Twitch)

### Key Elements
- Logo: Stylized "H" symbol in top-left
- Banner: High-contrast image with festival branding
- Status Badge: "SOLD OUT" prominently displayed
- Links: Red/green highlighted text for interactive elements
- Social Icons: Arranged horizontally in footer

### Design Philosophy
- **Dark, edgy aesthetic** reflecting heavy metal festival culture
- **High contrast** for readability on dark backgrounds
- **Metallic/textured** appearance
- **Minimal but impactful** layout
- **Clear information hierarchy**
